## How it was run

The runbook is the header of `services/fundamentals/src/fcf-backtest.ts`. Everything in this doc except the Answer, How it was run and Caveats sections is the script's output.

- The stack was this checkout's own Compose project at port offset 455. Only its Postgres ran, migrated and seeded.
- The weekly reference import loaded 10,054 listings from the GitHub release bundle dated 2026-10-05.
- **No SEC requests.** Every SEC body came from a copy of the 2026-11-21 run's cache (`.dev/sec-cache`, 25 companyfacts bodies and `company_tickers.json`, hashes checked against the original) through that run's fetch guard at a cap of 0. Each process logged 0 network requests, and the guard's request log kept the 26 lines it had. `fill:ciks` filled 5,936 issuers, as on 2026-11-21. The submissions endpoint was refused, as then.
- Splits came from Polygon `sync:splits` for the 25 listings, retried one at a time after HTTP 429s.
- Closes came from yfinance through the dev-providers sidecar (`capture:closes` on 2026-11-22). The captures were then cut to 2016-11-21 to 2026-11-20, the 2026-11-21 run's window, so prices match it.
- The same data was backfilled and backtested twice, first with origin/main (81b95125) and `backfill:sec-statements --annual-history-years 16`, then with this branch's backfill over the stored facts. That gave the 65 continuing-operations OCF originals main had left without a context their scope and a context, and stored 15 later 10-Ks' restatements of them, scoped too. Costco's backfill stopped on the same `eps_basic` unit error as on 2026-11-21, and JNJ's FY2024 balance sheet on the same `CommercialPaper` disagreement.
- **Scope marks.** Each free cash flow cell names the scopes it was computed in, as "Free cash flow (continuing-operations OCF less PP&E cash capex)". The doc was regenerated for them on a fresh stack at offset 490, from another hash-checked copy of the same cache, with this branch's backfill alone. - **Reproduction.** main's run matches the 2026-11-21 doc row for row except CAT, HD, MRK, PEP and QCOM, whose productive-assets capex #741 certified. This branch's run differs from main's only in rows that named `operating_cash_flow context_unverified`.
